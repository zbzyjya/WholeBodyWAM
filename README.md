# WholeBodyWAM

Project page for **WholeBodyWAM: Learning Whole-Body World Action Models with Scalable Motion Priors**.

## Local preview

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8000/`.

## Structure

- `index.html` — main project page
- `images/` — figures and favicon
- `videos/` — title background, demos, motion prediction, generalization
- `assets/` — CSS / JS (HTML5 UP Massively template)
